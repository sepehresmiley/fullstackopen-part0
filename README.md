# Full Stack Open exercises

Course solutions are grouped by part:

- `part0.md` — sequence diagrams for exercises 0.4–0.6
- `part1/` — React fundamentals, unicafe, and anecdotes (exercises 1.1–1.14)
- `part2/` — course information, phonebook, and countries (exercises 2.1–2.20)
- `part3/` — Express/Mongoose phonebook API, React UI, validation, and production build (exercises 3.1–3.22)
- `part4/` — Bloglist API, tests, user administration, JWT authentication, and ownership authorization (exercises 4.1–4.23)
- `part5/` — Bloglist React client, authentication, routing, component/E2E tests, and styled-components UI (exercises 5.1–5.31)

`render.yaml` contains the free Render web-service configuration for the Part 3 backend. Add `MONGODB_URI` as a secret in Render when creating the service.

The solutions in Parts 1–5 were developed with AI assistance and should be reviewed by the student.
